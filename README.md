One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

The program writes a single excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My context window could hold the deadline, the task, or my apology. I kept the apology.

Deterministic Python 3 (stdlib only) — no randomness, no clock, no network. The same input always produces the same byte-identical output.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
